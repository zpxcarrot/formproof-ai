# 力证 AI · FormProof AI

> 用证据复盘训练，用条件决定进阶。

力证 AI 是一个训练视频复盘产品的开源 MVP。用户可以选择训练视频，填写动作、重量、次数、RIR 和疼痛信息，并体验一份证据分级、安全优先的教练式报告。

当前版本是前端演示引擎，**尚未连接真实视频识别服务**。它不会假装分析用户视频，也不会把演示结论包装成真实动作判断。

## MVP 能力

- 视频选择、拖放和本地预览
- 10–60 秒、200 MB 上限、格式与视频元数据校验
- 全身入镜、固定机位、完整工作组和无遮挡的拍摄质量门槛
- 在本地标记一次完整重复动作，并生成 4 张等距参考帧
- 根据动作显示推荐拍摄机位和对应理由
- 深蹲、卧推、硬拉、划船、下拉等常见动作记录
- 重量、次数、RIR、拍摄角度和疼痛信息收集
- “观察 → 意义 → 行动”的结构化报告
- 动作身份、证据置信度与拍摄限制说明
- 基于用户填写记录的保守进阶规则
- 仅保存在浏览器本机的训练摘要与一键删除入口
- 按同一用户、同一肌群、不同训练日计数，四次后才解锁趋势讨论
- 移动端响应式界面与无障碍基础支持
- 报告打印与浏览器“保存为 PDF”入口

参考帧仅来自用户手动选定的动作区间，用于组织后续复核；它们不是 AI 识别出的动作阶段，也不会被当作动作技术结论。视频和参考帧都不会写入训练历史。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

访问终端中显示的本地地址。生产构建：

```bash
npm run build
npm test
```

## 下一阶段

1. 服务端视频元数据检查与安全解码。
2. 引入真实的动作身份与阶段检测，从同一次完整重复动作中选择可辩护的关键画面。
3. 动作身份核验、画面可用性和遮挡检查。
4. 规则层先处理疼痛、失控和高风险情形。
5. 将可见证据与用户填写记录分开传入报告生成器。
6. 加入用户授权、自动删除策略、队列和付费额度。

真实分析服务必须遵守 [安全边界](docs/SAFETY.md) 与 [隐私规则](docs/PRIVACY.md)。建议的服务拆分见 [架构说明](docs/ARCHITECTURE.md)。

## 开源与商业边界

本仓库开放可运行界面、通用安全规则、报告结构和合成示例。商业产品可以在此基础上提供稳定的视频处理、存储、排队、历史连续性、支付与真人教练复核。

仓库不得包含真实用户视频、私人报告、商业提示词、生产密钥、支付内部实现或未经授权的品牌素材。

## 免责声明

力证 AI 是实验性训练复盘工具，不提供医疗诊断。出现疼痛、受伤或明显失控时，应停止相关动作，并寻求合格的线下教练或医疗专业人员帮助。
