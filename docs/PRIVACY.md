# 隐私与数据隔离

## 当前演示版

- 选择的视频只在当前浏览器中本地预览，不发送到服务器。
- 浏览器仅保存动作、重量、次数和进阶摘要，不保存视频。
- 用户可以通过清除站点数据移除本机摘要。

## 生产版本最低要求

1. 每位用户的视频、报告、身体数据与训练历史使用独立的数据边界。
2. 未经明确授权，不得将用户媒体用于公开示例、宣传或模型训练。
3. 默认设置短期保留和自动删除，并让用户看见删除时间。
4. 日志不得包含视频内容、访问令牌、完整个人资料或本机绝对路径。
5. 公开仓库只允许合成素材或拥有明确公开授权的素材。
6. 删除账户时，应删除视频、报告、派生画面和可关联的训练记录。

真实用户视频、截图、私人报告和长期训练记忆不属于公开仓库内容。
